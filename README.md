Welcome to my main data portfolio. This repository showcases end-to-end projects focused on **Data Auditing, Data Cleaning (Wrangling), ETL Processes, and Executive Dashboarding**.

The main goal is to demonstrate technical proficiency in converting raw, fragmented, or improperly structured datasets into reliable, analysis-ready models and visual reports.

---

## 🛠️ Core Toolkit & Skills

* **Data Cleaning & Wrangling:** Python (`pandas`), Power Query, Regex, Address & Text Parsing, Anomaly Detection.
* **ETL & Data Consolidation:** Multi-source file merging, schema normalization, unpivoting complex structures.
* **Business Intelligence & Visualization:** Interactive Excel Dashboards, Dynamic Slicers, KPI Design.

---

## 📂 Project Directory

Below is an overview of the projects available in this repository. Each folder contains a dedicated `README.md` with detailed workflows and assets.

### 🔹 [`/data_cleaning_1`](./data_cleaning_1) — Customer Data Audit & Sanitation
* **Tech Stack:** Excel / Data Quality Techniques
* **Summary:** Performed an auditing and sanitation process on a dataset of 10,000 customer records to ensure consistency and eliminate structural errors.

### 🔹 [`/data_cleaning_2`](./data_cleaning_2) — E-Commerce Sales ETL & Data Cleaning
* **Tech Stack:** Power Query
* **Summary:** End-to-end cleaning and transformation process over raw e-commerce sales data (`messy_ecommerce_sales_data.csv`). Handled invalid data types, noise removal, and schema standardization for BI readiness.

* **Tech Stack:** Python (`pandas`)
* **Summary:** Structural transformation of a public dataset containing water and effluent sampling in Mendoza. Resolved double-header issues, pivoted flags, and text inconsistencies into a clean tabular structure.

### 🔹 [`/db_sales`](./db_sales) — Multi-File Excel Consolidation & Interactive KPI Dashboard
* **Tech Stack:** Power Query, Excel Dashboarding
* **Summary:** Automated the unification of 12 separate monthly Excel workbooks into a single scalable model. Built an interactive Excel Dashboard with 4-month term (*cuatrimestre*) dynamic filters.

# 📊 Portfolio de Limpieza de Datos, ETL y Analítica

[⬆️ Volver arriba / Back to top](#-data-cleaning-etl--analytics-portfolio)

Bienvenido/a a mi repositorio principal de datos. Este espacio reúne proyectos enfocados en **Auditoría de Datos, Limpieza (Wrangling), Procesos ETL y Creación de Dashboards Ejecutivos**.

El objetivo central es mostrar la capacidad técnica para transformar conjuntos de datos crudos, desordenados o mal estructurados en modelos confiables, normalizados y listos para la toma de decisiones.

---

## 🛠️ Herramientas y Competencias Clave

* **Limpieza y Estructuración de Datos:** Python (`pandas`), Power Query, Expresiones Regulares (Regex), Parseo de Texto, Detección de Anomalías.
* **ETL y Consolidación:** Unificación de múltiples fuentes, normalización de esquemas, despivoteo de estructuras complejas.
* **Inteligencia de Negocios y Visualización:** Dashboards Interactivos en Excel, Segmentación Dinámica, Diseño de KPIs.

---

## 📂 Índice de Proyectos

A continuación se presenta un resumen de los trabajos disponibles. Cada carpeta cuenta con su propio `README.md` detallado con el proceso técnico completo.

### 🔹 [`/data_cleaning_1`](./data_cleaning_1) — Auditoría y Saneamiento de Datos de Clientes
* **Tecnologías:** Excel / Control de Calidad de Datos
* **Resumen:** Proceso completo de auditoría y saneamiento sobre un conjunto de 10.000 registros de clientes para eliminar inconsistencias y asegurar la calidad de la información.

### 🔹 [`/data_cleaning_2`](./data_cleaning_2) — ETL y Limpieza de Ventas E-Commerce
* **Tecnologías:** Power Query
* **Resumen:** Proceso ETL de limpieza y transformación sobre un dataset de ventas online. Eliminación de ruido, corrección de tipos de datos no válidos y estandarización de esquema para análisis de BI.

### 🔹 [`/mendoza-agua-laboratorio`](./mendoza-agua-laboratorio) — ETL de Monitoreo de Agua y Efluentes
* **Tecnologías:** Python (`pandas`)
* **Resumen:** Normalización y estructuración de un dataset público de muestras de agua en Mendoza. Resolución de encabezados de doble nivel, banderas pivoteadas y texto no estandarizado mediante scripts en Python.

### 🔹 [`/db_sales`](./db_sales) — Consolidación de Excel Multifuente y Dashboard de KPIs
* **Tecnologías:** Power Query, Dashboard en Excel
* **Resumen:** Automatización del ensamblado de 12 planillas mensuales de Excel en una base única. Creación de un Dashboard interactivo con filtros dinámicos por cuatrimestre y análisis anual.
