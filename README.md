🛒 E-Commerce Sales Data Processing
🇬🇧 English Version
📝 Project Overview
This project contains the cleaning and preparation of an e-commerce sales dataset. The goal was to process a raw, unstructured dataset and convert it into a clean, standardized format ready for analysis.

📊 Data Source & Files
The raw data was downloaded from Kaggle:

👉 Messy E-Commerce Sales Dataset (File: messy_ecommerce_sales_data.csv).

Files included in this repository:

Original Data: Raw datasets in both .csv and .xlsx formats containing missing values, duplicates, inconsistent dates, and text formatting issues.

Clean Data: Processed datasets saved in both .csv (UTF-8 encoding) and .xlsx formats.

🧹 What Was Done
Data Inspection: Identified null values, duplicate entries, inconsistent date formats, and typos in text attributes.

Data Cleaning & Wrangling:

Handled missing data appropriately.

Removed exact and partial duplicate records.

Standardized date variables into a uniform format (YYYY-MM-DD).

Cleaned and normalized text fields (trimmed whitespace and corrected formatting errors).

Data Export: Exported the final cleaned data to CSV (UTF-8) and Excel formats for full cross-platform compatibility.

📝 Descripción del Proyecto
Este proyecto consiste en la limpieza y preparación de un conjunto de datos de ventas de comercio electrónico. 
El objetivo principal fue tomar un dataset bruto e inconsistente y transformarlo en un modelo limpio, estandarizado y listo para análisis.

📊 Fuente de los Datos y Archivos
Los datos originales fueron descargados de Kaggle:

👉 Messy E-Commerce Sales Dataset (Archivo: messy_ecommerce_sales_data.csv).

Archivos subidos en este repositorio:

Datos Originales: Archivos en formato .csv y .xlsx con los datos crudos que contienen valores nulos, duplicados, fechas inconsistentes y errores de texto.

Datos Limpios: Archivos procesados guardados en formato .csv (codificación UTF-8) y .xlsx.

🧹 ¿Qué se hizo con los datos?
Inspección de Datos: Se identificaron valores nulos, registros duplicados, inconsistencias en formatos de fecha y errores de tipeo.

Limpieza y Procesamiento:

Tratamiento de valores faltantes.

Eliminación de registros duplicados.

Estandarización de fechas al formato YYYY-MM-DD.

Normalización de campos de texto (eliminación de espacios extra y corrección de errores).

Exportación: Se guardaron las versiones finales en CSV (UTF-8) y Excel para asegurar máxima compatibilidad.
